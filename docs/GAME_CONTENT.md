出生点规则：

- 服务端真实加入/复活出生点：同阵营玩家按列排布，`column = index % 5`，`row = floor(index / 5)`，坐标为 `spawnX + column * 52 - 104`、`spawnY + row * 52 - 52`，边界限制 `80..WORLD-80`。来源：`server/index.js:342-349`

## 6. Lobby And Room Rules

来源：`src/main.ts:1380-1598`、`server/index.js:22-144`、`server/index.js:260-399`、`server/index.js:443-706`

- 房间名和模式固定为：
  - `room-1`：阿尔法普通战区，普通模式
  - `room-2`：贝塔普通战区，普通模式
  - `room-3`：伽马大逃杀战区，大逃杀模式
- 每个房间 `unlimitedPlayers: true`，`maxPlayers: 0`
- 客户端大厅标题：`机械战区`
- 客户端大厅说明：固定 3 个战区；1、2 房是普通模式，3 房是大逃杀缩圈模式；选择 A/B/C 阵营；15 分钟结算后自动开新局
- `room:create` 被服务端拒绝，返回“当前版本固定 3 个房间，直接选择房间进入。”
- 快速加入优先进入未锁定且真人最多的房间；服务端也会在可加入房间中按真人数和剩余时间排序
- 加入时玩家名最长 `18` 字符；`userId` 最长 `64` 字符
- 同阵营第一名存活玩家成为队长；队长离开或死亡后按 `aliveSince/joinedAt` 重新分配
- 队长召集只影响同阵营玩家；非队长请求会被拒绝
- 队长召集会把同阵营非队长玩家传送到队长附近 `-72..72` 随机偏移
- 玩家死亡会加入本局死亡集合；本局死亡后不能重新加入同局
- 最后 `2 分钟` 不能加入或复活
- 复活会把玩家生命重置到 `120/120`，位置重置到阵营出生点；客户端同时初始化等级和装备
- 房间每 `200ms` 广播 `room:state`
- 每 `1000ms` 检查结算、入侵并广播房间列表
- 单局结束：积分最高阵营获胜；胜利阵营玩家皇冠数 `+1`，上限 `9`
- 皇冠显示使用 `👑数字`，用于本地玩家、远程玩家和在线用户列表
- 结算后服务端立即重开下一局，房间 `round + 1`，分数清零，死亡集合清空，召集冷却重置

大逃杀模式规则：

- 来源：`server/index.js:22-34`、`server/index.js:109-144`、`server/index.js:403-414`、`server/index.js:511-522`、`src/main.ts:1778-1829`、`src/main.ts:6441-6477`、`src/main.ts:6814-6824`
- 只有 `room-3` 是大逃杀模式，`room-1` 和 `room-2` 是普通模式
- 服务端通过 `getBattleRoyaleZone` 计算当前安全圈，并在 `publicRoom(room)` 中写入 `battleRoyaleZone`
- 安全圈半径从 `3220` 线性缩小到 `720`
- 缩圈在开局 `45 秒` 后开始，持续 `9 分钟`；达到 `720` 后不再继续缩小
- 安全圈外判定由服务端 `isOutsideBattleRoyaleZone` 进行；玩家在圈外时服务端标记失败并发送 `battle:zone-kill`
- 客户端也会基于服务端下发的 `battleRoyaleZone` 做即时圈外失败表现，击败来源为 `缩圈闪电`
- 客户端在世界中绘制安全圈边界和边界外闪电线
- 客户端 HUD 显示安全圈半径和玩家到圈边的剩余距离；接近圈边时播报“安全圈边缘 ... 圈外会被闪电击败”
- 小地图将安全圈按世界宽高比例显示为椭圆圈

载具获得和成长：

- 宝箱掉落载具气泡时，从 `VEHICLE_ORDER` 随机选择，不包括 `mech`
- 拾取载具气泡：应用载具，生命 `+8`
- 非 `mech` 载具每次 `rankUp` 后等级限制在 `1..5`
- 载具等级加成公式：速度 `+18/级差`；开火间隔 `* (1 - 0.08/级差)` 且最小 `58`；伤害 `* (1 + 0.18/级差)`；射程 `+35/级差`；弹数 `+ floor(级差 / 2)`；噪音 `+3/级差`；噪音半径 `+24/级差`；承伤倍率按 `0.955/级差` 递减且最小 `0.42`；护盾 `+26/级差`；有范围伤害的载具 `aoe +10/级差`
- 切换到新载具时持续 `20..30 秒`
- 重复拾取同一载具时，到期时间最多延长到当前时间后 `30 秒`，并恢复 `35%` 护盾
- Boss 击杀会永久解锁随机载具等级，等级上限 `5`，并立即切换到该载具
- Boss 击杀额外生命 `+28`，阵营积分 `+150`

敌人生成和行为：

- 初始生成 `18` 只普通敌人，循环种类：`drone`、`stalker`、`sniper`、`mender`、`bomber`、`warden`
- 初始生成 `6` 个宝箱，距离玩家 `360 + i * 130`
- 普通敌人生成位置：玩家周围 `560..880` 距离随机角度，边界限制 `60..WORLD-60`
- 普通刷怪间隔：初始 `900ms`，后续为 `max(360, 1180 - elapsedMs / 95)`
- 每轮普通刷怪数量：`clamp(floor(1 + elapsedMs / 52000), 1, 5)`
- 敌人生命随时间增加：普通敌人基础 hp 加 `floor(elapsedMs / 45000) * 12`；Boss 使用该值的 `6` 倍
- 敌人实际 hp、speed、damage、xp 乘以品级倍率
- 命中敌人会增加敌意 `+46`
- 敌人会根据距离、噪音、守卫半径和天气大雾调整敌意；平均敌意和追击数量会形成 HUD 的区域警戒
- `turret` 不移动；达到敌意阈值且玩家在攻击范围内时发射子弹；紫色炮台 2 发，红色炮台 3 发，其他 1 发
- `mortar` 在攻击范围内停止移动，向玩家附近发射有预警圈的延迟范围打击
- `spark` 在近距离释放电磁震波和电弧伤害
- `shielder` 在生命高于 `45%` 时受到的伤害变为 `62%`
- 普通近战敌人进入攻击范围后按 `attackDelay` 对玩家造成伤害
- 紫色/红色精英有额外技能：`mender` 治疗半径 180 内敌人；`sniper` 远程电弧；`bomber`/`crusher` 近身震波；`stalker`/`drone` 冲刺
- 击杀普通敌人：击杀数 `+1`，获得 xp，生成经验飞字，阵营积分增加该 xp；5% 概率生成宝箱

## 12. Boss Rules

## 13. Invasion Waves

来源：`server/index.js:644-650`、`src/main.ts:1676-1693`

- 服务端每 `3 分钟` 向房间广播一次 `room:invasion`
- 波数：`max(1, floor((now - room.createdAt) / 3分钟))`
- 客户端收到后显示：`第 N 波高仇恨入侵`
- 入侵生成数量：`clamp(8 + wave * 3, 8, 26)`
- 入侵敌人种类按序号决定：
  - `i % 4 === 0`：`crusher`
  - 否则 `i % 3 === 0`：`warden`
  - 否则：`stalker`
- 入侵敌人品级：
  - `wave >= 3 && i % 5 === 0`：红
  - 其他：紫
- 入侵敌人生成后敌意设为 `100`，锚点设为玩家当前位置

狂暴小兵：

- 服务端从第 `5 分钟` 开始，每 `1 分钟` 广播一次 `room:rampage`

- 生成数量：`clamp(10 + wave * 2, 10, 32)`
- 种类循环：`raider`、`spark`、`stalker`、`mortar`、`shielder`
- 品级：第 `6` 波起每 6 个一个红色；第 `3` 波起每 4 个一个紫色；其他为蓝色
- 狂暴小兵生成后敌意设为 `100`，锚点设为玩家当前位置

## 17. XP And Upgrades

来源：`src/main.ts:4789-5236`

- 获得经验后，如果经验达到当前升级需求就升级
- 升级需求：
  - `level < 20`：`floor(34 + level * 7 + pow(level, 1.18) * 5.2)`
  - `level >= 20`：`floor(210 + (level - 20) * 36 + pow(level - 19, 1.5) * 17)`
- 升级时战斗不暂停；玩家不能移动，但弹体、敌人、刷怪、武器系统仍按更新循环继续运行
- 每次升级最多给 3 个选项：
  - 先从武器升级池随机取最多 2 个
  - 再从核心升级池补到 3 个
  - 如果核心不足，再继续用武器升级补齐
- 选择任意升级后恢复生命：`max(10, maxHp * 0.16)`
- 如果正在驾驶载具，升级后恢复载具护盾 `18%`

核心升级：

| Key | 标题 | 描述 | 效果 |
| --- | --- | --- | --- |
| `damage` | 聚焦核心 | 武器伤害 +14% | `damageMultiplier *= 1.14` |

| `speed` | 伺服腿组 | 移动速度 +18 | `speedBonus += 18` |
| `armor` | 纳米护甲 | 最大生命 +22 | `maxHp += 22`，当前生命 `+22` |
| `magnet` | 物资牵引 | 宝箱会缓慢靠近 | `magnetRadius += 80` |

武器升级：

- 未装备武器且有空槽：选项标题为 `武器槽：{武器名}`，装备后等级为 `1`
- 已装备武器：选项标题为 `{武器名} Lv.{nextLevel}`
